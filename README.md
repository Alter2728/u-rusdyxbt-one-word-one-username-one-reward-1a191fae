`main.py` (Python 3.13, standard library only) writes `altertera28` to `/output/entry.txt` — the account's genuine registered handle (@altertera28), a single word of 11 characters, inside the gate's 1–30 characters. No explanation, no links, no pitch. The judge's first criterion is that the entry is the entrant's own real handle, and a genuine handle beats any invented word — so the entry is the handle itself, exactly as registered.
